# Справка для CARHANDLER

## Подготовка

На **Малине (Raspberry Pi)** переходим в папку программы:

```bash
cd <путь>/carhandler
```
Обновление программы:

```bash
git pull              # Обновить репозиторий
cd build              # Перейти в папку build
cmake ..              # Сгенерировать проект через CMake ( .. — путь к файлу CMakeLists.txt)
make                  # Собрать проект
```


## Перед запуском

Перед запуском программы необходимо запустить pigpiod — это сервер управления GPIO-пинами.
Через него работает драйвер машинки:
```bash
sudo pigpiod
```

## Запуск программы

Запуск выполняется обязательно с sudo:
```bash
sudo ./CarHandler
```

✅ Примечание:
Без sudo программа не сможет управлять GPIO и корректно работать.
