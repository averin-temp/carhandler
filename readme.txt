
Справка для CARHANDLER

На Малине,  заходим в папку программы.  

cd  <путь>/carhandler


Обновление: 
git pull    
cd build    // перейти в папку build
cmake ..    // Сгенерировать проект через CMake ( ..  - путь к файлу CMakeLists)
make        // Сборка проекта



Перед запуском программы надо запустить pigpiod - это сервер управления пинами, через него работает драйвер машинки
sudo pigpiod  

Запуск программы:

sudo ./CarHandler

(sudo   обязательно)
